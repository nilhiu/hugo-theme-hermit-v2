# fonts

`sanae-braille.woff2` is the Braille Patterns block (U+2800-28FF) subset of
**Noto Sans Symbols 2** (© 2022 The Noto Project Authors), taken unmodified from
`@fontsource/noto-sans-symbols-2` (`noto-sans-symbols-2-braille-400-normal.woff2`).
Licensed under the SIL Open Font License 1.1, see `OFL-NotoSansSymbols2.txt`.

Metrics (units per em 1000): every glyph advances 700; the dot grid is 267 wide x 250 tall
per dot. The homepage mascot uses `line-height: 1` and `letter-spacing: -0.166em` so dots
land on an even square grid.
